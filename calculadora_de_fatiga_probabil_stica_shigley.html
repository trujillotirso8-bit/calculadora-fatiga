Fórmulas y Algoritmo Estocástico (Shigley)

Para fatiga axial/flexión completamente reversible, Shigley combina la variabilidad de los factores de modificación de Marin para obtener el coeficiente de variación de resistencia $C_S$:

$$C_S = \sqrt{C_{S_{ut}}^2 + C_{S'_e}^2 + C_{k_a}^2 + C_{k_b}^2 + C_{k_c}^2 + C_{k_d}^2}$$

Luego, la ecuación de interferencia acoplada (Ecuación de Shigley) resuelve el factor de diseño medio $n_d = \mu_S / \mu_\sigma$ exacto para cumplir con el nivel de confiabilidad $z_R$:

$$n_d = \frac{1 + \sqrt{1 - \left(1 - z_R^2 C_S^2\right)\left(1 - z_R^2 C_\sigma^2\right)}}{1 - z_R^2 C_S^2}$$
